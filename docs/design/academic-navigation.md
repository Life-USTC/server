# 教务导航与详情页 PRD

## 对象与用词

| 界面名称 | 指代对象 | 例子与使用位置 |
| --- | --- | --- |
| 课程 | 跨学期的课程目录条目 | 课程详情显示课程编号、课程简介和历次开班记录。 |
| 班级 | 某门课程在特定学期开设的一次授课实例 | 班级编号为 022063.01。订阅、考试、上课安排、作业和评论归属具体班级。 |
| 行政班 | 学生所属的行政编组 | 简介中列出面向的行政班。行政班与开课学期、授课教师分别展示。 |
| 教师、教室 | 具有独立详情页的人物和地点 | 教师入口显示姓名，教室入口显示房间名称或编号，例如 2304。 |

中文导航、列表、搜索、订阅和空状态使用上述术语。数据接口中的 Course、Section 及上游原文保留原义。班级入口统一摘要为「课程名（学期，教师）」，例如「热力学与统计物理B（2026年秋季学期，何志成）」。侧栏使用紧凑学期格式，可将「（2026秋季学期，何志成）」换到第二行。缺少学期或教师时省略该分项，课程名缺失时可用公开编号标识。

## 导航与页面

- 根侧栏直接展示工作台、日历、校园和校园活动及其下一级入口。进入作业、待办或考试时仍可直接切换同级页面。打开具体记录后才进入局部侧栏。
- 班级局部侧栏依次展示「返回」、当前班级摘要，以及子页「日程」「作业」。点击班级摘要直接进入简介。省去局部集合标题、全部班级入口和重复的页签标题。
- 班级、课程、教师各自的子页使用独立地址，支持直达、刷新、收藏和前进后退。以前的页签入口导向对应新页。每页采用单栏，并只装载当前内容。
- 面包屑依次展示集合、实体摘要和当前子页，简介省略重复节点。省去「查看所属课程」及「授课教学班」标签。长摘要保留全文，换行时尽量均分行宽并收紧分隔符间距。
- 教室、教师、课程、班级的详情入口在可点击名称左侧显示对应图标。文字使用普通前景色，键盘焦点清晰可见。教室详情有可分享的地址，展示可用的楼层、教学楼及位置图。无地图时如实展示缺失状态。

## 标题、内容与操作

- 面包屑、标题和正文共用内容宽度与左右边界。主标题下依次为副标题、学期和教师，再展示相应的公开编号。学期、教师和编号均使用副标题的小字号与颜色，编号用等宽字体。标题区留出上内边距，手机端尤其明显，底部加分隔线。桌面右侧操作相对于整个标题块垂直居中。
- 简介整合课程介绍、原更多资料和评论。学时、周学时、总学时、教师类型、考试形式等结构化事实集中排布，每项用图标标明含义，长字段允许自然换行。
- 日程上方展示期中、期末、小考等考试及空状态，下方展示上课安排。表头顺序固定为周次、课次、日期时间、地点。相邻同周的周次合并；同周内相邻且日期、时间均相同的单元格继续合并。地点逐行展示，仅显示教室短名；自由地点保留原文。课次和教师名共用基线，同一列的教师名在一位数及多位数课次旁对齐。
- 标题区只提供「订阅」。订阅弹窗处理班级订阅状态并提供进入日历的入口。「添加到日历」使用独立日历弹窗，以日历图标、标题和范围选项区分，可选择当前班级或全部已订阅班级。作业在独立页面展示。

## 桌面与手机验收

- 侧栏返回、导航行和折叠控件使用一致的 44 CSS px 点击高度。折叠按钮只显示图标，各交互状态背景透明、无边框，保留键盘焦点指示。
- 侧栏、菜单、顶栏与底栏共用对齐线、8 px 控件间距和适合触摸的边距。手机顶部从左到右先显示品牌，再显示侧栏开关；右侧登录使用带无障碍名称的图标，语言和主题入口移到抽屉。桌面主题选项使用屏幕设置图标表示跟随系统。
- 检查桌面与手机的正文宽度、横向溢出、标题区边线、长面包屑、授课教师和地点列、两种弹窗及侧栏点击高度。按实际测量绘制导航对齐标注图。当前页面截图使用高像素密度；PR 前后对比复用开工前同一页面状态的原始截图，只更新当前版本一侧。原图遗失且需重新拍摄时，省略该组对比。
