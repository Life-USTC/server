# Universal Homework Naming

Guideline for homework titles and descriptions across sections. Not schema-enforced.

## Title

Use exactly one pattern. Do **not** include course name, code, or section info.

| Pattern | When | Example |
|---------|------|---------|
| `第{N}次作业` | Numbered sequence (default) | `第一次作业` |
| `{主题}作业` | One-off / themed | `期中论文作业` |

Avoid: `第一章作业`, `组合数学第一次作业`, `CONT6102P 第一次作业`.

## Description

Fixed bullets, omit unknowns:

```markdown
- 题目：...
- 提交方式：...
- 提交地址：...
- 备注：...
```

- `题目：` — required when known; otherwise `未记录`
- Others optional (`电子版` / `纸质版` / URLs / deadlines / formats)
